# 首都圏鉄道学習PWA

路線図・クイズ・経路ゲームを通して、首都圏の鉄道を学ぶためのiPhone向けPWAです。

現在は第1段階の開発中です。鉄道データの利用条件を確認するまで、アプリには**動作確認用の架空路線網**だけを収録します。実在の駅・路線ではありません。

## 現在できること

- 架空の2路線・7駅を使った路線図の表示と駅選択
- 駅名・路線名からの検索と、選択路線の強調表示
- 初回の使い方案内と学習地域の選択
- 駅ごとの手動「覚えた」記録
- 駅順を問う4択・地図タップクイズと回答結果の端末保存
- クイズを閉じた後の続きからの再開
- 隣接駅を選んで目的地まで進む基本経路ゲーム
- 1操作戻す、到着後の明示的な経路確定、途中状態の自動保存
- 経路一覧からの組み直し、3段階の暗記表示、段階式ヒント
- 確定した経路の履歴表示、駅名・路線名検索、並べ替え、個別削除
- 架空ネットワークでの通常経路検索、始終点入替、順序付き経由駅、駅間数・乗換数別の候補表示
- 使わない路線を除外した経路検索と、検索条件を隠したまま経路ゲームへ引き継ぐ機能
- アプリ本体のオフラインキャッシュ
- 通信状態・オフライン準備完了・アプリ更新の案内
- iPhoneホーム画面用アイコンと、公開時のオフライン用ファイル自動点検
- 安定版・試験版・開発版で異なる保存領域

## Windowsでの起動

PowerShellでこのフォルダーを開き、次を実行します。

```powershell
pnpm install
pnpm dev
```

表示されたURLをブラウザで開きます。

## 確認コマンド

```powershell
pnpm test
pnpm run build
pnpm run verify:pwa
```

## 公開

`main` ブランチへ反映すると、GitHub Actionsが自動テストと公開用ビルドを行い、GitHub Pagesへ公開します。初回はGitHubのリポジトリ設定で、Pagesの公開元を「GitHub Actions」にする必要があります。

## 大切な注意

- 現在の路線図は架空データです。
- 実在する鉄道データは、再利用・加工・オフライン配布の条件を確認してから追加します。
- 学習記録は利用中のブラウザ内に保存されます。ブラウザのデータを消すと失われる可能性があります。

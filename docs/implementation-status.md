# 実装・確認状況

更新日: 2026-10-27

## 完了した最初の動作版

- 引継ぎZIPを展開し、仕様書をリポジトリ内へ配置。
- iPhone向けの下部4タブを用意。
- 架空の2路線・7駅による路線図、駅選択、隣接駅表示。
- 手動の「覚えた」記録。
- 駅順を問う4択クイズと回答履歴保存。
- 隣接駅を選ぶ基本経路ゲーム。
- 1操作戻す、無効移動の拒否、到着後の明示的な確定。
- 途中の経路と確定した結果の端末保存。
- 乗換、鉄道駅間、再訪を別々に集計。
- 安定版・試験版・開発版で保存先とオフライン用キャッシュ名を分離。
- GitHub Pages向けの自動テスト・公開手順。
- 初回のみ表示する使い方案内、学習地域選択、スキップ、設定からの再表示。
- 駅名・路線名の部分一致検索と、検索した路線の地図上での強調。
- 4択と地図タップを問題ごとに切り替えられる基本クイズ。
- 回答前・回答後を含むクイズ途中状態の自動保存と再開。
- 3問終了時の今回成績表示。未回答問題は不正解として記録しない。
- 経路ゲームの通過順一覧と、任意地点からの組み直し。
- 駅名のみ／駅名と路線名を隠す暗記表示。地図と候補一覧で共通番号を使用。
- 現在地から再計算する3段階ヒント（方向、路線、次駅）。使用による減点なし。
- 暗記表示、ヒント段階、経路一覧の開閉状態を途中状態として保存。
- 確定した経路の履歴一覧、通過順の展開、駅名・路線名検索、新旧順の並べ替え。
- 記録時の指標を再採点せず表示し、1件ずつ確認して削除できる画面。
- 架空データと確認済み接続だけを使う通常経路検索。
- 出発・目的駅の入替、複数の順序付き経由駅の追加・並べ替え・削除と条件保存。
- 鉄道駅間数が少ない候補と乗換が少ない候補を独立計算し、同一路径なら1件に統合。
- 駅順、利用路線、乗換位置、駅間・乗換・再訪・徒歩を表示。所要時間・料金は表示しない。
- 通常検索で使わない路線を指定し、その路線を除いた候補を表示。
- 出発駅、目的駅、順序付き経由駅、使わない路線を経路ゲームへ引き継ぎ、検索結果の経路は隠して再挑戦可能。
- 引き継いだ条件を途中状態と確定履歴に保存。ゲーム中の候補・ヒントも除外路線と経由順を反映。
- 通信あり／なし、オフライン準備完了、アプリ更新可能の状態表示。
- iPhoneホーム画面用PNGアイコンと、公開用ファイルがオフライン保存対象に含まれることを検査する公開手順。
- 経路検索条件に名前を付けて保存し、呼び出し・2段階確認付き削除ができるお気に入り。
- iPhoneで検索条件名の入力時に画面が自動拡大されない文字サイズ調整。
- 学習記録・クイズ・経路・お気に入りを、形式番号と各データ版を付けたJSONファイルへ安全に書き出す機能。復元は未実装。

# 要件一覧とリリース計画

## 製品要件
- 地図を中心とした探索型UX。四つの常設タブ: **地図 / 経路 / 学習 / 設定**。
- 地理ベースの簡略路線図。鉄道会社の色を保ち、駅・路線タップ、検索、ズームによる詳細度変更に対応。
- クイズは駅と路線の習得用。学習済み自己申告とクイズ成績に基づく習熟判定は別データ。
- 通常の経路確認と、自力でルートを組む経路ゲームは異なるモード。双方の条件を共有できる。
- 外部サービスの有料契約を原則不要とし、iPhoneの保存済みデータで主要機能を使用できる。
- 個人情報のアカウント登録・サーバー同期を必須にしない。

## 実装優先度
| フェーズ | 出荷判定条件 | 主な機能 |
|---|---|---|
| 第1段階 MVP | 首都圏重点地域で地図・基本クイズ・基本経路ゲームが端末保存付きで動く | 初期鉄道グラフ、地図、駅・路線詳細と検索、地図操作、駅順4択/地図クイズの最小構成、駅隣接ベース経路ゲーム、学習結果・進行中ゲーム自動保存、初回地域選択、基礎オフライン対応 |
| 第2段階 | 複雑な路線・制約付き探索が一貫して動く | 列車種別、通過駅、乗換・直通の確認済みパターン、徒歩駅間接続、複数経由点、除外条件、乗換最少/駅間移動最少比較、詳細ヒント |
| 第3段階 | 長期学習用の分析・管理が揃う | 期限を考慮した復習推薦、クイズ高度評価、ダッシュボード、履歴の検索・絞込、設定のお気に入り、データ更新差分と出典、JSON統合・復元と案内 |

注: フェーズ区分は実装順序であり、既決の最終製品仕様を削除するものではない。MVPにも将来拡張可能なデータ形式を使用すること。

## 保守・運用
- 安定版とテスト版を別URL/オリジンまたは厳密に分離された保存名前空間で公開。安定版データをテスト版が書き換えない。
- 鉄道データはアプリ資産とは別バージョンで管理し、起動時に更新を確認、検証成功時のみ安全な時点で適用する。
- 過去に確定したゲーム成績は鉄道改正で書き換えない。

# 経路ゲームの仕様

## 開始
- 出発駅/目的駅を地図・検索から指定、相互入替可。ランダム出題、地域や難易度による制約、手動設定に対応。
- 前回の条件と命名したお気に入りを保存。通常の経路検索から、始終点・複数の順序付き経由駅・除外ルールを引継ぎ可能。引継いだ検索結果の正解経路はゲーム開始時に隠す。
- 地図ラベルは全表示/駅名非表示/駅名・路線名非表示の三段階。出発・目的の表示例外は維持、目的地マーカー独立切替。

## プレイ
- 次駅は地図または候補一覧から追加。現在駅をタップしたときのみ有効候補を両方に連動表示。名称を隠した候補は共通番号で対応。
- 接続不明・禁止・停車しない種別の移動は受け付けず、短い理由を表示し詳細は任意展開。減点なし。
- 複数路線/接続が成立する場合に限り選択させ、一意の場合は自動確定。急行などを利用するときは明示的に種別を選択し、確認済み停車駅まで進行可能。
- 経由条件の進捗は常設の小さな概要と展開詳細に表示。条件を地図で全て明示して答えを漏らさない。
- 直前1操作の取り消し（Redoなし）。詳細一覧の地点タップは位置確認のみ。「ここから組み直す」で以降を切詰める。同じ駅への複数到着は履歴のインデックスで識別。原則確認ダイアログなし。
- 条件や始終点の途中変更を許可し、無効な区間を検出して案内、採点は最終条件で実施。無条件の減点なし。
- ゲーム中の経路一覧は通常はコンパクト、任意展開。停車駅を主表示、通過駅は件数をまとめて展開可能。隠しラベルは一覧・エラー詳細にも適用。
- ゲーム内現在位置を追従。手動パン/ズームで停止、専用ボタンで現在地へ復帰。短い線・マーカーのアニメーション。

## ヒント、終了、履歴
- ヒントは任意。段階1方向、段階2路線、段階3具体接続/乗換。現在地点と制約に合わせて再計算し、使用ペナルティなし。
- 目的駅に達したら到着表示。経路は編集可能であり、「この経路で確定」押下で記録する。目的駅通過後に別の駅へ進んだら、改めて目的駅へ戻る必要あり。
- 評価項目は列車乗換数・鉄道駅間数・再訪回数・徒歩接続回数（定義はrail-graph.md）。恣意的な総合点・推測所要時間なし。
- 比較候補は最少乗換と最少駅間、共通制約下で算出。元経路/比較経路は切替表示と任意重ね表示。鉄道色を保ちながら縁取り/線種で区別。
- 完了記録には安定ID・確定日時・実際の通過順・利用路線・種別・停車/通過・制約・指標・版を保存。最新順・出発/到着/路線検索・期間/乗換などの絞込と並替、個別削除（確認）。履歴は自動期限削除なし、保存容量警告とバックアップを案内。
- 再開可能なゲームは原則1件。フル状態（条件・現在駅・経路・表示状態・ヒント・鉄道データ版）を自動保存。明示的な中止は未完了扱い、確定した成績を生成しない。
- 鉄道データ更新で過去の記録を再採点しない。任意で最新版との相違を検査する。

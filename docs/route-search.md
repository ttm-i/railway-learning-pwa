# 通常の経路検索

- 地図または駅名検索で始終点を設定、入替可。順序付きの必須経由駅を複数設定し、再並替・削除可。
- 会社単位・路線単位の複数除外と徒歩駅間接続の許可/不許可を指定できる。制約により不可能な経路は、制約下で見つからなかった旨を理由付きで表示。
- 乗換最少と鉄道駅間数最少の2条件を切替。必要時に双方を地図上に重ね、同一パスなら一つにまとめる。
- 結果表示は地図上の経路強調と、駅順・乗車路線・乗換・直通の区別・構内乗換と駅間徒歩の区別・各種カウント。確認できない所要時間や料金を創作しない。
- 前回の始終点・経由地・除外条件などを復元し、名前を付けたお気に入りを編集・削除・JSONで持出し可能。経路検索自体の自動履歴は作らない。
- 検索結果から条件を引継いでゲーム開始。既に表示した正解は隠し、提示したパスに一致しなくても合法な経路なら正解になりうる。
- 徒歩区間と未確認接続の扱い、列車乗換の定義は `rail-graph.md` を唯一の規範とする。

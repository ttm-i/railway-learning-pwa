# UI・操作・初回案内

## ナビゲーション
- 下部固定タブ: 地図/経路/学習/設定。学習にはダッシュボード・クイズ・復習・習得詳細、経路には通常検索・ゲーム・ゲーム履歴を配置。
- 地図上の選択時は三段階高さのドラッグ可能ボトムシート。地図が操作できる状態を保持。
- 初回のみ学習地域を選び（初期値 東京23区、複数選択可）、地図/クイズ/ゲームを短く説明。案内はスキップ可、設定から再表示。再訪時は最後の地図中心・倍率を復元。
- ライト/ダーク/システム連動。線の実色は維持し、選択経路は装飾で識別。
- 地図の自動ラベル衝突解消、重なった駅の候補UI、名前の非表示でも操作可能な共通番号。
- 進行中のゲーム/クイズの自動保存と復帰をナビゲーションに統合。

## エラー/アクセシビリティ
- 無効な移動は経路を変更せず、短時間通知と任意詳細で説明。未確認接続と接続不可を区別。暗記モードでは隠した名前を漏らさない。
- 操作不能を避けるため、ゲームのアニメーション中でも入力を受け付ける。動きを抑える端末設定を尊重。
- アイコンや線の色だけに意味を依存させない。ボタンには状態とアクセシブルな名前を持たせる。
- 端末の位置情報は経路ゲームの「現在位置」に使用しない。

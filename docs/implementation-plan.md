# 第1段階 MVP 実装計画

作成日: 2026-10-26

## 目的

実在の鉄道データを配布せず、架空の小規模路線網を使って、路線図・基本クイズ・基本経路ゲーム・端末保存・オフライン起動を一通り検証する。

## 最初の実装範囲

1. iPhoneで使いやすい下部4タブ（地図・経路・学習・設定）。
2. 架空データであることを常時明示した簡略路線図。
3. 駅選択、駅詳細、手動の「覚えた」記録。
4. 駅順を問う4択クイズと回答履歴の保存。
5. 隣接駅を選んで目的地へ進む基本経路ゲーム。
6. 1操作戻す、到着後の明示的な確定、途中状態と結果の保存。
7. アプリ本体のオフラインキャッシュ。
8. 自動テスト、公開用ビルド、GitHub Pages公開手順。

## 今回は実装しないもの

- 実在する駅・路線・列車種別・直通運転・時刻・運賃。
- 急行、徒歩接続、複数経由地、路線除外などの第2段階機能。
- 実在データの更新配信、JSON統合、高度な復習推薦。
- Canvas/WebGLへの最終決定。最初は小規模検証に適したSVGを仮採用する。

## ファイル構成

- `src/data/` — 架空の鉄道データ。表示用の位置と経路計算用の接続を分離。
- `src/domain/` — 接続判定、経路指標、データ検査。
- `src/storage/` — 端末保存。安定版・試験版・開発版で保存場所を分離。
- `src/features/` — 地図、経路ゲーム、クイズ、設定の各画面。
- `src/components/` — 複数画面で使う表示部品。
- `src/test/` — 自動テストの準備。

## 完了の判断

- 架空路線網で駅選択、クイズ、経路ゲームが動く。
- 無効な駅移動で経路が変わらない。
- 到着だけでは結果にならず、「この経路で確定」で保存される。
- 再読み込み後も学習記録と途中のゲームが残る。
- 自動テストと公開用ビルドが成功する。

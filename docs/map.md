# 地図・駅・路線の機能仕様

## 表示
- 実地理に概ね沿った簡略路線図。線路接続は表示形状から推定しない。
- 元の路線色を保つ。選択路線の強調、始終端・停車駅・乗換駅の詳細。駅タップで駅名・所属路線・隣接駅・接続の詳細を下部パネルへ。
- 路線タップで強調、始終点・所属駅リスト・乗換情報を表示。
- ズームによる段階的ラベル表示、密集時のラベル衝突回避。選択駅・選択路線・重要乗換駅・始終点を優先。
- 河川・海岸線、自治体境界、自治体名等の地理補助情報を個別切替。
- タップ重複は候補が明白なら自動決定、複数なら選択肢を表示。
- 情報は3段階ドラッグ可能な下部シート。シート表示中も地図操作可能。
- 駅・路線検索で該当地点へズーム・選択し下部情報を開く。
- 前回の中心・倍率を復元。表示テーマはシステム追従/ライト/ダーク、路線色識別を維持。

## 経路ゲーム表示
- 作成済み区間は路線色を残した縁取りなどで強調。出発・通過済・現在・目的は形状等でも識別。再訪順は描画だけでなく経路データで維持。
- 出発と目的を初期表示時に収める。目的地マーカーは任意に非表示にできる（駅名を隠すモードとは独立）。指定経由駅の位置を勝手に明かさない。
- 現在駅をタップしたときだけ、次の有効候補駅・路線を地図上とシート一覧で同時表示。双方で同じ候補を選択可能。
- 名前を隠す表示では候補番号を地図・一覧に共通表示し、名称から正解を漏らさない。
- 自動追従中は進行先へ移動。ユーザーがパン・ズームしたら一時停止。ゲーム内現在駅へジャンプするボタンで再開（GPS位置とは別）。ズームは原則維持。
- 「1操作戻す」は地図に常設し、途中地点からの「ここから組み直す」は詳細シート内。選択のタップだけでは経路変更しない。
- 短い線描画と現在駅マーカーの連動アニメーション。連続操作をブロックしない。prefers-reduced-motionに相当する設定を尊重。

## パフォーマンス優先順位
1. 現在位置・始終点・選択駅・作成済み経路
2. 接続候補・乗換・選択路線・必要なラベル
3. 画面外/遠方ラベル、路線形状の細部、地理表示
4. 装飾・非必須アニメーション

経路計算グラフは表示範囲に依存せず、描画のみ最適化。Canvas/SVG/WebGL等は実測選定。

# 首都圏鉄道学習PWA 開発引継ぎパッケージ

- 仕様版: **v10.9（Q1〜Q110確定）** / 2026-10-26
- プラットフォーム: **iPhone中心、無料運用のPWA**。iOS Safariでのホーム画面追加を想定。
- 目的: 首都圏の駅・路線・運行系統を地図で把握し、クイズと経路作成ゲームで習得する。
- 対象地域: 東京23区、川崎市、横浜市を先行検証、接続が必要な区域外の駅・線も維持し首都圏広域へ拡張。
- **本パッケージは実装仕様と引継ぎ資料であり、動作するアプリのソースコードではない。**

## 読む順序
1. `requirements.md` — 固定目標・MVP境界・開発段階。
2. `data-model.md` と `rail-graph.md` — ID、ネットワーク、評価の唯一の定義。
3. `map.md`、`quiz.md`、`route-game.md`、`route-search.md`、`ui.md` — 機能ごとの要件。
4. `offline-and-backup.md` — 保存・同期なし運用・データ更新。
5. `testing.md` — 受入条件・テストケース。
6. `open-issues.md` — 未確定で、推測実装してはいけない事項。
7. `decision-log.md` — Q1〜110の意思決定の索引。**正式仕様が優先**。

## AI開発時の規則
- 仕様に書かれていない鉄道情報、到着時間、運賃、運行時刻や停車パターンを創作しない。
- UIモックはデザイン例で、技術選択や寸法の固定ではない。
- 未確定事項を推測で正式仕様に格上げしない。`open-issues.md`に提案・仮実装・検証方法を記録する。
- 第1段階の実装時でも、駅・線・サービス・接続のIDは後方互換可能に設計する。
- 試用版と安定版の保存先・キャッシュ・公開先は分離する。
- 鉄道データの権利を確認してから配布。バックエンドを必須とせず、保存済みデータでオフライン動作する。

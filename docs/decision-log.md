# 決定履歴（Q1〜Q110）

本ファイルは決定の索引・要約。詳細な動作要件は機能別正式仕様を優先。各行は会話で確定した選択の意味を要約したもの。

- **Q1** — 地図中心の探索UI
- **Q2** — 地理ベースの簡略路線図
- **Q3** — 通常は駅名表示・暗記では隠す
- **Q4** — 駅タップで詳細・隣接駅
- **Q5** — 路線タップで強調・駅リスト
- **Q6** — ズーム詳細度を段階変更
- **Q7** — 暗記のヒント・4択
- **Q8** — 手動習得とクイズ自動推定の分離
- **Q9** — 元の路線色維持と駅の習得マーク
- **Q10** — 最終地図位置・倍率を復元
- **Q11** — 駅・路線検索
- **Q12** — 通常経路確認と自力経路ゲームの両立
- **Q13** — 到達の成功と効率評価の分離
- **Q14** — 地図タップ/パネルで経路を組む
- **Q15** — ランダム・範囲指定・手動始終点ゲーム
- **Q16** — ゲームのラベル表示3段階
- **Q17** — ヒント任意・無効移動を拒否し理由表示
- **Q18** — 自分の経路と代替経路を比較
- **Q19** — ダッシュボードで進捗・正答率・弱点
- **Q20** — 手動/誤答/間隔を使う復習提案
- **Q21** — 首都圏広域データ・学習範囲選択
- **Q22** — 急行等停車パターン収録・出題
- **Q23** — 確認済み直通は0乗換
- **Q24** — 構内乗換と駅間徒歩を別種の接続として扱う
- **Q25** — 河川/海岸/行政境界等を個別切替
- **Q26** — ラベル重複回避と優先順位
- **Q27** — 駅タップ候補の曖昧性解決
- **Q28** — 高さ3段階のボトムシート
- **Q29** — 常設の地図/経路/学習/設定タブ
- **Q30** — 自動/ライト/ダークテーマ
- **Q31** — IndexedDB保存＋手動JSONバックアップ
- **Q32** — データ別JSON・起動時更新チェックと復旧
- **Q33** — データ全体と路線別の検証日・出典管理
- **Q34** — 駅改称・統廃合に伴う履歴移行と保存
- **Q35** — 駅全体と路線×駅の学習を分離
- **Q36** — 地図と特定路線表示で習得マーク切替
- **Q37** — 手動習得と自動習熟を別保存
- **Q38** — 近時正答・連続・間隔から習熟推定
- **Q39** — 復習の間隔と提案件数を柔軟化
- **Q40** — 自動/3/5/10/20問題の件数
- **Q41** — 回答後の正答・解説・地図ハイライト
- **Q42** — 4択・地図タップ・文字入力
- **Q43** — 回答形式を事前選択・前回設定記憶
- **Q44** — 名前表記揺れを許容、誤字は再確認
- **Q45** — クイズ時間制限なし
- **Q46** — クイズ自動中断再開・一件のみ
- **Q47** — 正答率・誤答一覧・即時誤答再挑戦
- **Q48** — 難易度自動提案＋初中上級手動
- **Q49** — 複数地域/路線・中心駅周辺から範囲設定
- **Q50** — クイズ条件の前回復元と名前付きお気に入り
- **Q51** — ゲーム出発/目的を地図・検索指定
- **Q52** — 始終点マーカー・目的地マーカー独立非表示
- **Q53** — 1操作戻す＋途中地点切詰め・Redoなし
- **Q54** — 同一駅再訪許可・過大ループ保護
- **Q55** — 目的駅到着後『この経路で確定』で採点
- **Q56** — 乗換/駅間/再訪を個別評価
- **Q57** — 乗換最少・駅間最少の両参考経路
- **Q58** — 比較経路は切替・任意の重ね描画
- **Q59** — 方向→路線→具体接続の3段階ヒント
- **Q60** — ゲーム自動中断再開・一件のみ
- **Q61** — ゲーム条件の前回復元・名前付きお気に入り
- **Q62** — ゲーム成績・全パス・データバージョン保存
- **Q63** — 履歴一覧の検索・絞込・並替・個別削除
- **Q64** — ゲーム履歴は期限・件数で自動削除しない
- **Q65** — 7/30/90日/全期間の指標・欠損はN/A
- **Q66** — 全網→路線/地域→駅の進捗ドリルダウン
- **Q67** — 学習推薦理由・各種並替
- **Q68** — 進捗から地図/クイズ/ゲームへ遷移
- **Q69** — ダッシュボードにKPI・学習推薦・再開
- **Q70** — 地図/経路/学習/設定の4タブ分担
- **Q71** — 通常検索は経路/乗換/区間・徒歩等を説明
- **Q72** — 乗換最少・駅間最少を切替・重ね表示
- **Q73** — 事業者/路線除外・徒歩接続オンオフ
- **Q74** — 複数の順序指定必須経由駅
- **Q75** — 検索条件の前回復元・名前付きお気に入り
- **Q76** — 通常検索結果から同条件でゲームへ
- **Q77** — 経由駅・除外をゲームへ引継ぎ編集可
- **Q78** — 条件達成の最小常設チップ＋詳細展開
- **Q79** — ゲーム中の始終点/経由駅/除外を変更可
- **Q80** — 経路縁取りと役割別マーカー
- **Q81** — 現在位置タップ時のみ有効候補表示
- **Q82** — 地図上の候補とパネル一覧を連動
- **Q83** — 暗記モードは名称を隠し共通候補番号
- **Q84** — 経路概要＋展開可能な通過履歴
- **Q85** — 一覧タップは位置確認・専用組み直しボタン
- **Q86** — 1操作戻す常設・組み直しはパネル内
- **Q87** — 自動追従・自由探索時停止・戻るボタン
- **Q88** — 経路線と現在マーカーを短いアニメで連動
- **Q89** — 路線が一意なら自動・複数なら選択
- **Q90** — 列車種別を選択して停車駅まで進行
- **Q91** — 停車駅を基本表示・通過駅は展開
- **Q92** — 実際の別列車乗継のみ乗換1
- **Q93** — 乗換/徒歩回数/鉄道駅間を別指標
- **Q94** — 無効移動の短い理由＋任意詳細
- **Q95** — 未確認接続は使用しない・不足と表示
- **Q96** — 過去成績は固定・最新版との差異を任意確認
- **Q97** — 安全な自動更新＋通知＋変更履歴
- **Q98** — 地図/クイズ/検索/ゲーム/履歴のオフライン
- **Q99** — 初回地域選択＋短いスキップ可能案内
- **Q100** — 地図・基本クイズ・基本ゲームから段階開発

- **Q102** — オープンデータ＋公式照合
- **Q103** — 修正記録＋自動検証＋関連テスト
- **Q104** — 上書き/統合選択＋復元前スナップショット

- **Q107** — 重要駅/経路を優先し装飾を段階簡略化
- **Q108** — 安定版とテスト版を分離
- **Q109** — 全体＋機能別＋技術仕様＋質問履歴

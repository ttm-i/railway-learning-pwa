# クイズ・習得管理・復習

## 習得モデル
- 駅の全体習得と「路線×駅」の習得を別に記録。地図全体表示では駅全体、特定路線を選択するとその路線の習得マークを表示。
- 手動の「覚えた」チェックと、自動推定の習熟度を完全分離。手動チェックはクイズ結果で勝手に変更しない。
- 自動習熟推定は直近正答・連続正答・復習間隔を考慮。時間だけで急激に低下させない。
- 問題出題は選択地域・複数路線・中心駅の周辺・初級中級上級または自動推薦。利用可能問題数を表示。
- おすすめ学習は復習期限・最近の間違い・未出題/未学習を理由付きで提示。『未学習』を自動的に『苦手』とは呼ばない。

## クイズセッション
- 回答形式: 4択 / 地図タップ / 駅名テキスト入力。複数形式を選択して出題、前回の形式を記憶、初期値は4択と地図タップ。
- 駅名入力は正式表記・かな表記・駅の有無・余分な空白など妥当な揺れを受理。軽微な誤字は本人に確認してから採点し、無条件に正答扱いしない。
- 制限時間なし。問題数は自動調整または3/5/10/20等の指定。
- 回答後は正答・短い解説と位置を地図上で強調し、自由に次へ進める。
- 出題進捗を自動保存。タブ移動、アプリ終了後再開可。中断セッションは原則1件。途中終了は回答済み分だけ採点し、未回答分は誤答にしない。
- 終了画面に正答率・間違えた問題・地図ハイライト・誤答のみ再挑戦を表示。即時再挑戦と間隔を置いた習熟を別の記録として扱う。
- 出題条件は前回復元＋命名したお気に入りの作成/変更/削除。JSON対象。

## 学習ダッシュボード
- 7/30/90日/全期間の期間フィルター。問題数・正答率・推移。無回答期間は0%とせず『対象なし』。
- 現在の手動学習済み数、期間内の正答率、自動習熟度を明確に分離。
- 全域→路線/地域→個別駅のドリルダウン。地域計数では共通駅を重複カウントしない。
- 絞込/並替: 路線順、名前順、手動未習得、低い推定習熟度、次の復習予定など。
- 地図ハイライト、範囲指定クイズ、関連する経路ゲームへ遷移可能。中断中ゲーム/クイズの状態を壊さない。
- 上部は要約指標・おすすめ課題・再開導線、下部に詳しい進捗。
